## NEON COAST

لعبة متصفح عربية صغيرة بعالم مدينة ساحلية مفتوح، مستوحاة من ألعاب العالم المفتوح (وليست GTA VI أو نسخة منها). تتضمن قيادة سيارات، مشاة، مطاردة شرطة، خريطة مصغّرة ومهمة قابلة للعب.

### التشغيل

افتح `index.html` مباشرة، أو شغّل خادم ملفات محلياً من مجلد المشروع:

```bash
python3 -m http.server 3002
```

ثم افتح `http://localhost:3002`.

### التحكم

- `WASD` أو الأسهم: حركة / قيادة
- `E`: دخول السيارة أو النزول منها
- `Space`: فرامل يدوية
- على الهاتف: أزرار لمس ظاهرة على الشاشة

اللعبة تضبط دقة الرسم حسب شاشة الجهاز، لكنها لعبة Canvas ثنائية الأبعاد وليست لعبة AAA ثلاثية الأبعاد، ولا يمكن ضمان 4K/30fps على كل جهاز.
